# Kokomonster Japanese Festival — layered vector artwork

- `kokomonster-festival-layered.svg`: editable 1254 × 1254 SVG master.
- `preview.png`: rendered visual preview, not the editable master.
- `official-logo.png`: unchanged supplied official logo, provided separately.

The SVG is a newly drawn interpretation of the festival concept. Characters, props, title panels, and decorative motif groups have separate named SVG groups with Inkscape layer labels. It contains no embedded raster artwork or auto-traced pixel contours. Curves and shapes remain editable.

The tagline is live SVG text in two independently editable lines: やさしい / 日本語. The font stack is Hiragino Sans, Noto Sans JP, sans-serif; weight 800. Install a matching font to preserve layout on other computers. Applications may handle imported SVG text differently, so confirm text editability after import. The SVG itself preserves text rather than outlines.

The six characters are Koko, Gohanko, Rabbit, Bear, Yauyau, and Tree. Held objects are separate layers; smaller face and clothing details remain vector shapes within character groups. Background, sun, mountain, snow cap, clouds, lanterns, fan, drum, waves, petals, and accent groups are separately selectable.

The reference is the composition and character-style benchmark, not a pixel-accurate source. Poses, facial details, typography, decorative placement, and flat vector finishes differ from the original generated artwork.

The official logo is omitted from the all-vector master because the available official asset is PNG. It is supplied unchanged alongside the SVG, not redrawn or embedded. An approved vector logo is needed for a completely vector-branded final composition.

No Figma frames were changed for this deliverable.
