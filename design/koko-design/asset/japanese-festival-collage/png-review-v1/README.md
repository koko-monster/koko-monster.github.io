# Festival PNG assets — review batch 1

Open `index.html` to review the real PNG transparency on checkerboard, cream or dark backgrounds.

## Included

- `koko.png`: Koko with held uchiwa, 1254 × 1254.
- `bear.png`: Bear with happi, taiko and drumsticks, 1254 × 1254.
- `lantern.png`: standalone festival lantern, 1254 × 1254.
- `folding-fan.png`: standalone pink sakura fan, 1536 × 1024.
- `prompts.json`: complete built-in image-generation prompts and reference paths.

Status: review candidates, not approved or assembled in Figma. Characters preserve the supplied PNG direction; props use the original festival collage as reference. Koko and Bear's held props remain combined with their character for this first visual checkpoint. Other characters, independently movable held props, and remaining motifs are pending.

All four files have an alpha channel with fully transparent pixels. Visual checks performed in a browser against checkerboard and dark backgrounds. The raw RGB hidden behind transparent pixels can appear as stray colors in previews that ignore alpha; judge the files through an alpha-aware renderer such as this HTML page or Figma.

After approval, extend the character/prop set and assemble PNG objects as separately named Figma layers. Keep the Japanese title やさしい日本語 as editable text and the official logo unchanged. This batch makes no Figma changes.
